One Line, One Laugh — a make.fun entry. A single funny line, capped at 200
characters, written to make a reader laugh out loud on a first read.

## The line

> I told my smart fridge I'm dieting, so now it hides the cheese and texts me 'we need to talk' at midnight.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt`. That's the whole
entry — nothing else is submitted.

```sh
node main.ts
cat /output/entry.txt
```
